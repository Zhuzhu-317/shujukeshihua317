# 基础数据集构建

## 一列一个变量，一格一个数据

按用户要求，每列定义一个明确变量，每个单元格只存放一个值。字段可为名义、量化、图像或文本数据。多条记录按行存放，每行的记录单位先写明。

| 数据类型 | 单元格的内容 | 字段示例 |
|---|---|---|
| 名义 | 一个名称、类别或编码 | 名称、地区代码、类别 |
| 量化 | 一个数值 | GDP数值、数量、评分 |
| 时间 | 一个时间值 | 年份、日期 |
| 位置 | 分列保存一个坐标分量 | 经度、纬度 |
| 图像 | 一个图像文件路径或资源ID | 图像路径、图像ID |
| 文本 | 一条有界定的文本记录 | 一段引文、一条评论 |

文本作为一个字段值时可以包含标点，记录边界由分析任务确定。需要分析词频时，再从文本记录提取词项。图像列每格关联一张图片，另设来源字段说明其出处。

## 原子化处理示例

| 原始内容 | 拆分方式 |
|---|---|
| 某地GDP为120亿元 | 地区名称、GDP数值、单位分列 |
| 名称＋GPS坐标对 | 名称、经度、纬度分列，坐标系单独说明 |
| 一个对象的多张照片 | 图像表每行一张图，用对象ID关联 |
| 一个对象的多个标签 | 标签关联表每行一个对象ID与一个标签 |
| 同时包含两年的数值 | 用年份列与数值列构成长表，或每个年份一个独立字段并说明用途 |

## 记录单位与表结构

| 表 | 每行代表什么 | 主键 | 关联字段 |
|---|---|---|---|
| 对象表 | 一个对象 | 对象ID | 来源ID |
| 观测表 | 一个对象在一个时间或条件下的观测 | 观测ID | 对象ID、来源ID |
| 图像表 | 一张图像 | 图像ID | 对象ID、来源ID |
| 文本表 | 一条文本记录 | 文本ID | 对象ID、来源ID |

按实际选题采用所需结构，具体数据文件在采集后建立。

## 构建检查

检查每行记录单位、唯一ID、同列类型、重复、缺失、单位与日期格式。量化值与单位分列，零值与缺失值分别编码。派生指标写明公式和输入字段，保留与原始资料的对应。
