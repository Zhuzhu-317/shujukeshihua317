# 叙事框架搭建

## 用字段组合形成明确主题

每个叙事模块由一个问题、若干字段、必要计算和可解释的结论组成。先核对数据是否足以支持主张，再安排作品的阅读顺序。

| 字段组合 | 可以形成的信息 | 需要补充的条件 |
|---|---|---|
| 名称＋经度＋纬度 | 地图上的地点信息 | 坐标系、范围与位置精度 |
| 地区名称＋GDP数值 | 某地区GDP信息 | 年份、币种、单位、统计口径与来源 |
| 名称＋年份＋数值 | 某对象的变化过程 | 时间粒度、缺失记录与可比性 |
| 类别＋数量 | 类别比较或构成 | 共同分母、单位及是否互斥 |
| 文本ID＋文本＋词项统计 | 主题词与文本关注点 | 分词、停用词、权重与上下文 |
| 对象ID＋图像ID＋描述 | 图像条目或视觉对照 | 图片选择条件与来源 |

以上为结构示例，实际主题结论待选题与数据确定。

## 阅读顺序草案

主题与背景 → 总览 → 核心发现 → 证据展开 → 对照或例外 → 结论与来源。可按时间、空间、分类或问题组织，记录采用顺序的理由。

## 核实事项

检查每个模块的输入列是否存在、计算可否复核、单位是否一致、标题主张是否有证据。涉及原因时补充相应依据，表中相关与差异需按其证据范围解释。
