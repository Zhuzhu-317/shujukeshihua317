## 调研任务

1. 梳理主题背景、关键概念、相关主体与争议。
2. 观察目标读者的知识基础、关注点与阅读场景。
3. 查阅已有研究、公开资料和相关信息图形案例。
4. 初步判断哪些问题有可用证据，哪些问题需要自建数据。
5. 将可验证的研究问题带入主题内容分析。
