## 工作流程

调研确定问题 → 与大模型讨论主题与类型标签 → 按需求搜集资料 → 构建原子化基础数据集 → 用字段组合形成叙事模块 → 完成视觉编码与设计表达 → 补充信息轮盘测试 → 制作并迭代成品。

阶段之间可根据新证据返回修订。对话、资料、数据字典、叙事与设计决定分别记录在对应原文件中。

## 基础数据与叙事约定

每列定义一个变量，每格保存一个值。名义、量化、图像与文本字段均需明确记录单位，图像可使用单个资源ID或路径，复杂关系使用ID关联。

名称与位置可形成地点叙事，经度和纬度各占一列。地区名称与GDP数值可构成经济主题，解释时还需年份、单位和统计口径。字段组合、计算与叙事主张在第五阶段逐项对应。
