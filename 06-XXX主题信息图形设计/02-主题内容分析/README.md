# 主题内容分析

## 与大模型共同完成的分析

把调研发现、资料摘录、候选数据字段和案例图交给大模型，逐轮讨论主题范围、数据关系、阅读目的与设计选择。记录每次结论的依据和仍需核实的部分。

### 可直接使用的沟通提纲

我的选题是 XXX，目标读者为待填写，传播场景为待填写。请依据我提供的资料和字段，分析哪些研究问题能够得到证据支持，判断适合的数据逻辑、表现类型和视觉风格，并给出字段依据、备选方案及待补充材料。请把已经观察到的事实、分析建议和待核实内容分别说明。

## 类型与标签决策

| 分析层面 | 候选项 | 选定项与依据 |
|---|---|---|
| 数据逻辑 | 编年型、层级型、编目型、字母表型、地理图形型，可组合 | 待讨论 |
| 表现类型 | 混合型、文字型／列表型、时间轴型、比较型、图片式、词云图等 | 待讨论 |
| 视觉风格 | 平面、照片、手绘、3D 等，可组合 | 待讨论 |
| 基础设计方式 | ISOTYPE、图标系统、图文对应等 | 待讨论 |
| 主要统计任务 | 比较、变化、构成、分布、关系或空间定位 | 待讨论 |

这些层面可以共同描述同一作品。例如，时间数据支持编年逻辑，照片资料支持图片式表达，ISOTYPE 可作为基础设计方式标签。最终组合由主题和证据决定。
