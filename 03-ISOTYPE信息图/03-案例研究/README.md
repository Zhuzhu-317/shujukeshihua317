# 03 案例研究

## 现有课程案例

“行业就业与失业，1932年”的原有分析完整保留在[概念与方法：课件案例分析](../00-ISOTYPE概念与方法.md#课件案例分析)。

原记录依据课件第59页：按行业排列，以重复人形符号和颜色呈现就业与失业比例；每个符号表示相应行业工人的5%。该描述沿用原标签文档，后续补充原作来源并核对图注。

## 案例分析记录项

- 来源、作者或机构、年代、课件页码及原图位置。
- 数据对象、指标、单位、分母与统计范围。
- 符号含义、重复规则、排列、颜色和图例。
- 视觉叙事、阅读顺序、比较任务与可能的误读。
- 可借鉴的方法、证据状态与待核实事项。

案例可同时关联02中的类型分类；ISOTYPE作为基础设计方式记录。
