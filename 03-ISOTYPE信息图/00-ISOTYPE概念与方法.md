# ISOTYPE 基础设计方式

| 标签属性 | 内容 |
|---|---|
| 标签名称 | ISOTYPE |
| 分类层级 | 基础设计方式 |
| 使用范围 | 可跨信息图形类型使用 |
| 主要关注 | 图形符号、数量单位、重复排列、视觉比较与公共理解 |
| 课程依据 | 《第三讲-信息图形类型学》中 ISOTYPE 专节，PDF 第 59 页行业就业案例 |

## 概念

本课程将 ISOTYPE 作为基础设计方式标签，记录图形符号如何把数据和概念组织成便于识别、比较和理解的视觉语言。它可以参与混合型、比较型、列表型及单一图表型作品的设计。

分析时关注符号的语义、单位换算、重复规则、排列和图例，以及这些规则怎样共同支持信息交流。标签可以与案例的类型同时记录，例如“比较型＋ISOTYPE”。

## 基础设计原则

1. 建立符号语义。同一符号表示同类对象，符号的变化应有明确含义。
2. 明确计量单位。记录一个符号代表的数量或比例，并交代分母与统计范围。
3. 以等大符号的重复数量组织数量比较。尺寸、间距和排列应支持计数与横向阅读。
4. 统一颜色与类别对应。颜色区分对象、状态或类别，并与图例一致。
5. 说明余量处理。遇到部分符号、四舍五入或不足一个单位的数值，记录采用的表达规则。
6. 保留必要语境。标题、年份、对象、单位、来源与文字解释共同帮助读者理解。

以上原则为依据课程案例整理的分析方法，后续结合原作与课程材料继续校订。

## 课件案例分析

### 行业就业与失业，1932年

课件第 59 页左侧作品以行业为行，使用统一的人形符号重复排列，并用颜色区分就业和失业。图注明确每个符号表示相应行业工人的 5%。

- 数据组织采用行业与就业状态的交叉比较。
- 图符数量表达行业内部的比例，一个完整符号对应五个百分点。
- 行业识别符号、人形计量符号与状态颜色承担不同作用。
- 各行业分别以自身工人总数作为分母，读者可比较比例差异。
- 行业总人数需要额外数据，图中的人形数量应按已给出的百分比单位解释。

该作品展示了重复符号、统一单位和规则排列如何支持统计比较。课程记录可采用“案例类型＋基础设计方式标签”的方式组织。

## 案例标签使用规则

对案例使用“ISOTYPE”标签时，在原案例文件内写明采用依据，至少记录符号含义、数量单位和重复或比较规则。只观察到一般图标时，可先记录为“图标辅助”，待补齐证据后确定标签。

建议记录格式如下。

| 项目 | 填写内容 |
|---|---|
| 案例类型 | 混合型、比较型、列表型等 |
| 基础设计方式 | ISOTYPE |
| 符号语义 | 人、车辆、建筑等对象及其含义 |
| 单位与分母 | 单个符号对应量、统计范围与时间 |
| 数量与排列 | 重复规则、分行分组、余量处理 |
| 使用依据 | 对应图例、画面或课程材料的位置 |

## 可关联的信息图形类型

- [混合型](../02-信息图形类型案例/01-混合型信息图形/README.md)可将图符计量与其他统计图形组合。
- [文字型／列表型](../02-信息图形类型案例/02-文字型-列表型信息图形/README.md)可用统一图符组织条目与局部数量比较。
- [比较型](../02-信息图形类型案例/06-比较型信息图形/README.md)可用统一单位和重复排列支持对象间比较。
- [单一图表型](../02-信息图形类型案例/10-单一图表型信息图形/README.md)可围绕一个主要统计任务组织图符。

这些链接表示方法的可应用范围，具体案例的使用状态以原图证据为准。
