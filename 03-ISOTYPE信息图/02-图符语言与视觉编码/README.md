# 02 图符语言与视觉编码

## 现有方法

依据[概念与方法](../00-ISOTYPE概念与方法.md)中的原有分析，整理以下设计观察项：

| 观察项 | 需要说明的内容 |
|---|---|
| 符号语义 | 同一符号代表什么对象，符号变化是否有明确含义 |
| 单位与分母 | 一个符号对应的数量或比例，统计范围和时间 |
| 重复与排列 | 等大符号如何重复、分行、分组并支持比较 |
| 色彩与图例 | 颜色对应哪些类别或状态，图例是否一致 |
| 余量处理 | 部分符号、四舍五入与不足一个单位的处理方式 |
| 阅读语境 | 标题、年份、单位、来源与文字解释是否完整 |

以上为原课程案例整理的方法，后续结合原作继续核实与完善。
