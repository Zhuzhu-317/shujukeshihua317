# 04 设计实践

## 实践流程

1. 明确主题、阅读对象与需要完成的比较任务。
2. 整理基础数据，记录对象、数值、单位、分母、时间与来源。
3. 定义图符语义，确定单个图符对应的量。
4. 统一图符尺寸、重复排列、分组、颜色与图例。
5. 记录不足一个单位、部分图符及四舍五入的处理规则。
6. 检查读者能否识别对象、理解单位并完成比较。
7. 保存设计方案、反馈、修改理由和经验。

流程依据原[概念与方法](../00-ISOTYPE概念与方法.md)中的原则整理。
