# 08 均匀连通性原则（Principle of Uniform Connectedness）

## 定义与概念

在明度、颜色或纹理等视觉属性上具有一致性，并且连通的区域，倾向被组织为一个知觉单元。

## 理论来源与适用条件

[Palmer与Rock（1994）知觉组织论文](https://link.springer.com/content/pdf/10.3758/BF03200760.pdf)

均匀连通性研究关注视觉场中初始知觉单元的形成，继而讨论单元之间的分组与部分分解。

## 基础示意与课程案例

本篇采用课程构造示例，实际作品及来源在后续分析中补充。

以连续同色带状形态组织相关信息，使其形成可识别的整体。

## 设计分析

检查区域是否连通，视觉属性是否连续。关系图中的连线还需另行说明其数据语义。

分析时分别记录输入内容、元素的语义关系、视觉编码和版式安排，再核对读者感知到的组织是否与预期一致。可记录字段与对象、标题与图形、标签与数据及模块之间的对应。

## 与其他原则的协同或冲突

初始单元形成后还可继续分组或分解，需分别观察与相似、接近的关系。

## 设计实践方案

比较连续区域、断开区域和属性突变区域，观察整体识别的变化。

上述为拟执行的测试方法。根据实际任务确定观察指标，可包含分组准确性、查找时间、追踪错误和理解复述，记录参与者、任务和呈现条件。
