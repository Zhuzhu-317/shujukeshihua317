# 案例分析与原则协同

## 分析任务

一张信息图通常包含多个知觉组织因素。先列出对象与语义关系，再辨认实际使用的间距、颜色、边界、轮廓、运动与图底线索。记录协同与竞争各自发生的位置。

## 构造案例一　标题与三组指标

任务是让读者把每个标题与对应图形、数值和注释归为一组。

- 接近。观察标题与自身模块的距离，以及它与相邻模块的距离。
- 相似。观察相同颜色是否把跨模块元素组织起来。
- 共同区域。观察底色或边框是否重建模块归属。
- 图底。检查照片或纹理背景中的标签识别。

设计分析先固定内容，分别改变间距、色彩、容器和背景。让读者指出模块边界和标题归属，记录错误位置，再判断何种线索支持任务。

## 构造案例二　交叉路线

任务是沿同一对象的路线从起点找到终点。可同时观察良好连续、相似色及连通形态。比较交叉角、断口和颜色改变后的追踪情况，并核对路径的真实数据含义。

## 构造案例三　图符比较

任务是读懂两组重复人物图符的数量或比例。可观察接近分行、相似形状、共同区域和对称比较的作用，同时核对单符号单位、分母和余量处理。
