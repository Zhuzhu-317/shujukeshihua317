# 03 闭合原则（Law of Closure）

## 定义与概念

在适当条件下，不完整的边界可以被视觉系统组织为完整形状。

## 理论来源与适用条件

[Wertheimer（1923，1938年译本）](https://psychclassics.yorku.ca/Wertheimer/Forms/forms.htm)

本专题依据经典知觉组织讨论整理。其表现受画面条件及其他组织因素影响。

## 基础示意与课程案例

本篇采用课程构造示例，实际作品及来源在后续分析中补充。

区域示意中用局部边界和角标提示分区，同时为内容保留空间。

## 设计分析

观察缺口是否仍支持识别，是否导致错误补全。精确数值或地理边界的缺失需要另行核实。

分析时分别记录输入内容、元素的语义关系、视觉编码和版式安排，再核对读者感知到的组织是否与预期一致。可记录字段与对象、标题与图形、标签与数据及模块之间的对应。

## 与其他原则的协同或冲突

良好连续、对称及背景条件会影响形状补全。

## 设计实践方案

逐步增加轮廓缺口，记录对象识别与分区判断何时改变。

上述为拟执行的测试方法。根据实际任务确定观察指标，可包含分组准确性、查找时间、追踪错误和理解复述，记录参与者、任务和呈现条件。
