# 03 编目型信息图形概念定义

> 课程依据：《第三讲-信息图形类型学》第 2、10-13 页及后续编目混合案例。

编目型以一组可识别条目及其属性为核心，通过分类、排序、检索或并列比较组织信息；它不要求天然的时间顺序或父子层级。

## 课件中的核心口径

课件把编目型（Cataloged Infographics）列为五种数据架构逻辑之一，并用谱系、作品目录、流向关系和径向汇总等案例说明：关键不是固定版式，而是把对象转化为可枚举、可分类、可比较、可交叉检索的条目集合。一个作品可将编目逻辑与编年、地理或层级逻辑混合。

## A 基本的数据逻辑

- 实体为条目、对象、作品、人物或概念。
- 最小字段为 `item_id`、`name`，可增加 `category`、`attributes`、`value`、`unit`、`rank`、`source`。
- 主关系为同类归组、属性相似、并列、排序、筛选和交叉索引。
- 应处理别名、重复、缺失属性，并区分主分类、筛选条件和说明标签。

## B 统计图形、统计方式与计算方式

常用表格、清单、卡片网格、点图、条形图、图标阵列、小倍数和比较矩阵；常计算条目数、分类频数、比例、排名、分布与属性交叉统计。排序依据应公开，不同单位或量纲不可直接比较。

## C 视觉编码

符号建立条目识别；线用于真实关联；卡片分隔模块；色彩编码类别、状态或评分；名称、属性和值构成检索核心；栅格、对齐、留白和重复样式帮助扫读。

## D 数据／信息架构

条目主表 → 属性、单位和词表规范 → 排序、筛选和统计 → 总览、类别索引、详情与比较 → 纳入标准、来源和版本。

## E 视觉叙事架构

范围与纳入标准 → 总览 → 主要分类 → 典型与异常条目 → 横向比较 → 索引与来源。须明确主要模式是线性叙事还是自由查阅。

## 与列表型的边界

编目型描述底层数据如何组织；文字型／列表型描述成品如何呈现。条目可以被画成树、流线、圆环或卡片，因此编目型不等于简单列表。
