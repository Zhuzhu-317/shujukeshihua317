# 05 地理图形型信息图形概念定义

> 依据《第三讲-信息图形类型学》，PDF 第 2、17–21、28 页。页码按阅读器顺序计数。下文区分课件原述、案例归纳和一般实施方法。

地理图形型以位置、区域、距离、方向、邻接或流动等空间关系为基本逻辑。仅用地图轮廓作装饰不属于地理图形型。

## A 基本的数据逻辑

- 实体为地点、区域、路线、空间事件或地理对象。
- 最小字段是地点标识或区域编码及坐标／几何信息，可增加 `value`、`category`、`time`、`source`。
- 主关系为位置、包含、邻接、距离、方向、路径、流动和空间聚集。
- 应使用稳定编码连接属性和地理对象，并说明坐标系、尺度、边界版本和聚合层级。

## B 统计图形、统计方式与计算方式

常用分级设色、比例符号、点密度、流向、等值线、蜂窝和变形地图；常计算总量、比例、率、密度、距离、区域汇总和流量净值。基数差异大时优先比较率或密度；分级方法和区间须记录。

## C 视觉编码

地理位置是主要编码；点表示地点或事件；线表示边界、路径或流向；面色编码率或类别；三维只在高度有意义且不遮挡时使用；连续、发散和定性色阶须匹配数据类型。比例尺、方向、图例和来源不可缺失。

## D 数据／信息架构

底图与边界 → 区域编码和度量 → 空间连接、归一化与分级 → 总览、重点区域和局部放大 → 边界争议、缺失、不确定性与来源。

## E 视觉叙事架构

空间范围与尺度 → 整体分布 → 聚集或差异 → 重点地区／路径 → 区域对照 → 来源与限制。切换尺度时须说明分母、边界和聚合层级是否变化。

## 课件口径与案例归纳

第 17–21 页展示城市平面、山岳剖面、河湖分布、河道历史与城市小倍数图，第 28 页展示地标型。下列补充是对图例空间组织方式的归纳。

### A–E 的课程应用

- A 空间实体可以是城市、区域、河流、路线或地貌。虚构城市也可具有明确的空间关系，应标明其设定性质。
- B 地理图形可以直接呈现位置和形态，也可结合长度、高度、流量或区域统计。地图中的面积、长度、数量须分别说明尺度和单位。
- C 点表示地点，线表示水系或路线，面组织区域，剖面或体积效果解释地貌。同一图中示意比例与精确比例应有清楚说明。
- D 地理底图、统计属性、时间版本、图例与注释共同构成架构。第 20–21 页河道图还需要历史时间与河道轮廓之间的对应。
- E 从空间总览进入局部，或沿路线和河流推进。城市小倍数图需要统一比较口径。

比例尺、方向与图例应按任务配置。示意路线可以强调连通性，虚构空间可以强调定位与区域关系。详见[地理案例对照](../02-信息图形类型案例/README.md#数据逻辑案例对照)。
