# 01 编年型信息图形概念定义

> 课程依据：《第三讲-信息图形类型学》第 2-5 页及后续编年型案例。

编年型以时间次序、间隔、持续或周期作为组织信息的首要关系；仅画一条时间轴并不足以构成编年型。

## 课件中的核心口径

- 数据逻辑：单向、不可逆、顺序排列。
- 数据维度：单维为主，较少延伸数据。
- 视觉编码：线性为主，具有高度可变性。

“不可逆”指主阅读顺序由时间推进决定，不等于版面只能使用直线；课件案例同时展示了环形、螺旋和折返路径。

## A 基本的数据逻辑

- 实体为事件、阶段、时间点或区间；主关系包括先后、同时、持续、间隔、重复和转折。
- 最小字段为 `event_id`、`title`、`start_time`，可增加 `end_time`、`category`、`value`、`source`。
- 时间须说明粒度、历法、时区和缺失值；区间须区分开始、结束与持续时间。

## B 统计图形、统计方式与计算方式

- 常用时间轴、折线、柱形、面积、点图、甘特图、事件带和小倍数图。
- 常计算事件数、分期汇总、持续时间、相邻间隔、累计值、变化量、增长率和移动平均。
- 不等时间间隔不应画成等距离；若叙事压缩，须明确提示。

## C 视觉编码

位置编码时间；点表示事件；线表示连续变化或过程；面表示阶段、区间或累计量；符号和文字标注性质、来源与转折；色彩区分类别、阶段或状态。装饰性连线不得暗示不存在的因果。

## D 数据／信息架构

原始材料与证据 → 时间和实体标准化 → 派生指标 → 总览／轨道／重点事件 → 图注、出处、不确定性与更新时间。

## E 视觉叙事架构

背景与范围 → 总体进程 → 阶段 → 关键转折 → 对照或结果 → 来源与限制。可以回溯，但不能用先后关系代替因果证据。

## 课程方法补充

课件把叙事性信息图形流程概括为：数据收集与清洗 → 数据集与结构搭建 → 视觉编码与版式排布 → 数据关联与内容呈现。编年型应先确定时间粒度和主顺序，再选择线性、环形或混合路径。
