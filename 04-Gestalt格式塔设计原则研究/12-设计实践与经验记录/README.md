# 设计实践与经验记录

## 记录目的

本文件汇总跨原则、跨案例的设计经验。当前已准备实践方案和记录模板，实际测试结果待补充。已有理论依据、设计预期与现场观察分别注明。

## 实践流程

明确读图任务 → 保存原方案 → 确定调整变量和保持条件 → 制作对照 → 观察读者 → 记录差异 → 修订方案 → 标明经验的适用边界。

## 可观察指标

- 分组。读者如何划分对象、模块和段落。
- 对应。标题、注释和图例是否归属到预期图形。
- 查找。完成指定信息查找所需时间与错误。
- 追踪。路径在何处被误读、切换或丢失。
- 理解。能否复述主题、关系与主要发现。
- 呈现。尺寸、屏幕、打印、动态时序等条件如何影响结果。

根据任务选择指标并记录观察方法，必要时兼顾定性反馈和定量记录。

## 经验形成

经验写明具体条件与结果，例如“在某种画布与阅读任务下，改变组间距离后标题归属错误减少”。持续比较不同方案，保留例外和尚待复核的结果。
