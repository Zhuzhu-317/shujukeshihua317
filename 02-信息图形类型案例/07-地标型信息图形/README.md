# 07 地标型信息图形（Location Infographics）

资料依据为《第三讲-信息图形类型学》PDF 第 28 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

围绕地点、路线和空间分布组织信息，通过地图、位置标识和地理注记支持定位、旅行或空间理解。

## A 基本的数据逻辑

地点、区域、路线与连接组成空间关系，地理属性和事件资料可附着到位置。

## B 统计图形与计算方式

主题地图与交通网络图承担定位和连通任务。距离、费用、时间等计算需要各自的标注或尺度依据。

## C 视觉编码

位置、路线颜色、节点、地名和图例建立地理编码，主题插图提供地方特征与事件说明。

## D 数据／信息架构

空间范围 → 主路线或区域 → 地点节点 → 属性与注记 → 图例。

## E 视觉叙事架构

沿路线推进或由总览进入局部，通过地点串联信息。

## 案例分析

### 07-01 巴西至美国驾驶主题图

美洲地图与路线、地点插图和说明结合，将地理范围转化为旅行问题的阅读背景。

### 07-02 纽约交通网络图

线路色彩、站点和换乘关系构成检索系统，读者按出发点、目的地和连接关系规划路径。

## 核实与后续补充

核实地图采用真实比例还是示意布局。交通线路的连通关系与实际地理距离分别核对。
