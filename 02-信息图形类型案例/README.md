# 02 信息图形类型案例

本目录保存案例材料、图片、逐案分析与阶段性总结。当前未收到课件和案例图片，因此先建立类型说明与统一模板，不对具体作品作推测。

## 类型入口

- [混合型信息图形（Mixed Charts）](./01-混合型信息图形说明.md)
- [文字型／列表型信息图形（Informational / List Infographics）](./02-文字型与列表型信息图形说明.md)
- [时间轴型信息图形（Timeline Infographics）](./03-时间轴型信息图形说明.md)

## 单个案例的最低记录项

1. 编号、标题、作者／机构、年份与来源链接。
2. 原始图片或获授权文件，以及版权／使用说明。
3. 案例类型及同时采用的数据逻辑。
4. A 数据逻辑；B 统计图形与计算；C 视觉编码；D 信息架构；E 视觉叙事架构。
5. 证据、局限、反例和分析日期。
6. 可归纳原则及应回写到文件夹 01 的链接。

## 图片与链接规则

- 图片只保存在本目录或其子目录，不复制到文件夹 01。
- 文件夹 01 只用相对 Markdown 链接指向案例。
- 未确认来源或版权的图片先记录外部链接，不擅自重新发布。

## 更新流程

新增案例 → 逐案分析 → 同类比较 → 提炼原则 → 更新文件夹 01 → 检查双向链接。结论必须能回到课件页码或案例证据。
