## 选题、制作与检验

课件第 40 页强调内容特点、可视化形式与读者背景之间的匹配。分析先写清读者需要回答的问题，再确定信息深度和编码方式。

第 43 页给出制作流程。下表把流程转化为可检查的工作结果。

| 阶段 | 工作结果 |
|---|---|
| 数据收集与清洗 | 来源、范围、单位、缺失值和去重记录 |
| 数据集与结构搭建 | 实体、字段、关系、分组和主指标 |
| 视觉编码与版式排布 | 字段到位置、长度、面积、颜色和符号的对应 |
| 数据关联与内容呈现 | 概览、证据、细节、解释、图例与出处 |

第 44 页列出初学者常见问题，包括未理解数据导致的复杂、忽略读者导致的抽象、美感不足和整合不足导致的堆积。修改时先定位问题对应的制作阶段。

第 42 页展示阅读路径、理解和记忆的研究方法。课程练习可先让读者回答主题、变量、强调部分和事实／评论四类问题，再观察其找信息的路径。课件提及的眼动记录、5 分钟和 2 周记忆测试属于测试方案，实施情况与结果需另行记录。

## 测试轮盘与表达原则

第 45–53 页的测试轮盘使用六组维度，包括抽象／模拟、实用／修饰、致密／稀疏、多维／单维、创新／通用、简洁／冗余。它帮助描述取舍，课件没有给出统一分值、权重或最优轮廓。应结合读者任务说明每一项选择。

第 54–57 页强调准确、清晰、有效及数据／油墨比。数据／油墨比可理解为承载数据信息的视觉标记占全部图形标记的比例。保留支持理解的单位、图例、标题、尺度与注释，逐项判断装饰的作用。

第 58–61 页介绍 Otto Neurath 与 ISOTYPE，即 International System of Typographic Picture Education。第 59 页行业就业图、第 61 页出生与死亡图使用重复符号进行比较。案例实施时应写明一个符号代表多少、残缺符号如何折算，以及不同组是否同尺度。这里的折算检查是案例分析方法。

第 63–72 页把信息图形视作表达观点和视觉交流的工具。先理解数据结构，再选择表现形式，提供概要、内部细节和逻辑导航。编辑归纳应保留信息依据，让读者能追查数据和判断。

## 单个案例的最低记录项

1. 编号、标题、作者／机构、年份与来源链接。
2. 原始图片或获授权文件，以及版权／使用说明。
3. 案例类型及同时采用的数据逻辑。
4. A 数据逻辑；B 统计图形与计算；C 视觉编码；D 信息架构；E 视觉叙事架构。
5. 证据、局限、反例和分析日期。
6. 可归纳原则及应回写到文件夹 01 的链接。

## 图片与链接规则

- 图片只保存在本目录或其子目录，不复制到文件夹 01。
- 文件夹 01 只用相对 Markdown 链接指向案例。
- 未确认来源或版权的图片先记录外部链接，不擅自重新发布。

## 更新流程

新增案例 → 逐案分析 → 同类比较 → 提炼原则 → 更新文件夹 01 → 检查双向链接。结论必须能回到课件页码或案例证据。
