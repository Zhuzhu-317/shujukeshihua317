# 08 图片式信息图形（Photo-graphic Infographics）

资料依据为《第三讲-信息图形类型学》PDF 第 29 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

以摄影图像提供对象、情境或视觉材料，并将统计图形、数字、注释和版式与照片结合。

## A 基本的数据逻辑

照片关联具体对象或场景，统计量关联国家、时间或主题类别。需要保持图像对象与数据对象的对应。

## B 统计图形与计算方式

健康主题案例组合条形及圆形对照，机构资料页组合照片和数值。具体比例、变化量和面积编码以图例核实。

## C 视觉编码

摄影裁切、明暗、遮罩和高对比文字帮助图文叠加，条形边界与数值维持可读性。

## D 数据／信息架构

主题与主照片 → 数据模块 → 对象和时间说明 → 图例与来源。

## E 视觉叙事架构

照片建立情境和兴趣，图表补充证据，再用说明解释比较结果。

## 案例分析

### 08-01 健康与人口指标版面

人物及生活照片被嵌入或铺在条形背景中，并与年龄、体重和医疗人员等统计模块组合。

### 08-02 AGLC 资料长页

按现状、优先事项、未来等栏目组织照片、图标、数字和文字，形成机构主题的纵向阅读。

## 核实与后续补充

照片的裁切、主体大小和背景不得改变数据图形的尺度解读。核实摄影是否仅提供情境。
