# 13 视觉简历信息图形（Visual Resume）

资料依据为《第三讲-信息图形类型学》PDF 第 34 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

把个人经历、教育、技能和作品方向组织为视觉资料页，以明确的模块和阅读顺序支持身份识别与能力了解。

## A 基本的数据逻辑

个人作为核心对象，经历具有时间属性，技能、语言和服务领域形成类别集合。

## B 统计图形与计算方式

可观察到年份列表、图标组及部分图形化能力表达。技能条或评分的含义、基准和主观性须按实际作品说明。

## C 视觉编码

肖像、姓名、职业标题、大字、图标和色块建立信息层次，分区与对齐支持快速查阅。

## D 数据／信息架构

身份与联系 → 教育和经历 → 技能与语言 → 项目、服务或个人说明。

## E 视觉叙事架构

先认识人物和职业定位，再查找与阅读任务相关的经历及能力证据。

## 案例分析

### 13-01 黑白视觉简历

大字和照片形成身份入口，教育、经历、个人设计理念和服务栏目分区排列。

### 13-02 红色视觉简历

Education、Experience、Skills 和 Languages 等栏目以红色、字级和规则框架组织。

## 核实与后续补充

图标出现可用于表示技能类别，熟练程度需要可解释的依据。简历中的年份、任职和作品信息按原文核实。
