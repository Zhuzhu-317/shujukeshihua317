# 03 时间轴型信息图形（Timeline Infographics）

资料依据为《第三讲-信息图形类型学》PDF 第 24 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

以事件的时间位置、先后次序和阶段变化组织阅读，将人物、地点、作品及说明附着于对应事件。

## A 基本的数据逻辑

格罗皮乌斯生涯和建筑作品由年份关联，人物、地点和作品分别是事件属性。环形路径承载主时间顺序。

## B 统计图形与计算方式

以年份定位与事件排序为主。时间间隔、持续时长和事件数可作为分析项目，只有图中明确表达时才记录为实际计算。

## C 视觉编码

环形线、年份节点及引线连接建筑图片，红黑两色建立重点，中心肖像与背景地图共同提供主题和空间语境。

## D 数据／信息架构

人物概览 → 时间路径 → 关键年份 → 建筑、地点与说明。

## E 视觉叙事架构

从人物进入其经历与作品，用时间路径建立进展，用建筑图像突出关键事件。

## 案例分析

### 03-01 包豪斯／格罗皮乌斯生涯与作品

中心肖像、环形年份、外围建筑图像和地理背景共同组织人物叙事。作品与年份通过引线对应，需识别明确的起点与读图方向。

## 核实与后续补充

核对环上间距是否按时间比例绘制，避免由排版距离直接推算持续时间。核实建筑年份和人物经历需结合原始文字。
