# 14 手稿型信息图形（Hand-drawn Infographics）

资料依据为《第三讲-信息图形类型学》PDF 第 35 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

采用手绘线条、手写字样和插图组织信息，形成适合主题的阅读风格。底层结构仍需说明分类、空间或关系规则。

## A 基本的数据逻辑

航海知识包含术语、方向、器具和动作等类别，城市鸟瞰图包含建筑、街道与位置关系。

## B 统计图形与计算方式

主要采用知识示意、局部图解和空间地图。图中尺度与数据统计是否存在需逐项确认。

## C 视觉编码

手绘线条、字形、色彩、局部放大和指示线建立风格及语义，密集版面通过分区与留白组织。

## D 数据／信息架构

主题全景 → 分区或知识类别 → 局部图解 → 名称与注释。

## E 视觉叙事架构

通过整体画面形成兴趣，再鼓励在局部反复探索和查阅。

## 案例分析

### 14-01 航海知识主题手绘图

图中航向、风、船帆、绳结等知识以手写术语、插图和方向关系共同组织。

### 14-02 城市鸟瞰手绘图

街道、建筑与密集标签形成空间全景，适合分析手绘风格如何承载位置和细节。

## 核实与后续补充

手绘是表达方式，空间、分类和数量关系还需单独说明。检查线条与文字的清晰度及高密度下的导航。
