# 01 混合型信息图形（Mixed Charts）

资料依据为《第三讲-信息图形类型学》PDF 第 22 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

围绕共同主题组合多种统计图形、文字、符号和图标，以统一的信息架构组织不同指标和比较任务。

## A 基本的数据逻辑

按环境、交通、客户满意度、工作场所分组，每组包含若干指标与年份。指标的单位、时间范围和比较对象需要分别记录。

## B 统计图形与计算方式

画面包含条形、扇形、圆形和重复人物图符，可用于数值、构成、分布及跨期比较。不同单位的指标分别建立尺度，图符换算关系依据图例核实。

## C 视觉编码

主题图标建立栏目识别，条长及扇形比例表达数量关系，统一色彩、对齐和字级形成四栏秩序。圆形面积是否按数值缩放需核对原图。

## D 数据／信息架构

主题总览 → 四个主题栏目 → 栏目内指标 → 数值、单位与年份 → 来源。

## E 视觉叙事架构

先扫描四个主题，再进入局部对照。每个栏目通过小图与说明提出局部发现，整体形成组织表现的多方面画像。

## 案例分析

### 01-01 四栏指标汇总

环境栏以能源、用水和排放等主题图标引入，交通栏组合比例与通勤信息，客户栏集中使用水平条形，工作场所栏使用人物图符与数值。多种形式对应不同指标任务。

## 核实与后续补充

逐项核实单位、年份和分母，比较不同年份时检查统计口径。图标的重复数量与排列是否承担精确计数，需要查看原始图例。

## 关联的基础设计方式

[ISOTYPE](../标签-ISOTYPE基础设计方式/README.md)可用于重复图符的数量比较。分析本页人物图符时，应先核实单个符号的计量单位、重复规则和图例，再记录具体标签采用依据。
