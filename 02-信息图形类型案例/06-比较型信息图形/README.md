# 06 比较型信息图形（Comparison Infographics）

资料依据为《第三讲-信息图形类型学》PDF 第 27 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

把两个或多个对象放在共同的指标框架中，通过并列和对称布局呈现相同点、差异及变化。

## A 基本的数据逻辑

对象共享一组可比较属性，关系包括横向比较与两个时期的对照。

## B 统计图形与计算方式

可见对向条形、比例圆、图标和人口年龄结构对照。金额、比例和总数需要分别核实单位、分母、年份及尺度。

## C 视觉编码

两侧位置、双色、对齐基线和相同指标顺序帮助配对。人物姿态与肖像增强对象辨识。

## D 数据／信息架构

比较对象 → 指标分组 → 配对数值与图形 → 背景解释 → 来源。

## E 视觉叙事架构

先辨识对象，再按指标逐项阅读，最后归纳差异及其可能解释。

## 案例分析

### 06-01 梅西与克里斯蒂亚诺·罗纳尔多

人物分置左右，中央图形与下方信息对照个人、职业和成绩资料，适合分析对称布局与指标配对。

### 06-02 西班牙两个时期的对照

左右对应历史人物与时期，组合经济、人口等图形，形成跨时比较。

## 核实与后续补充

检查双方采用相同统计范围和尺度，背景不同的指标需要解释可比条件。对向条形以各自基线读取长度。
