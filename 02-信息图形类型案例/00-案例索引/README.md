# 00 案例索引

本目录按《第三讲-信息图形类型学》PDF 第 22—38 页的出现顺序收录 16 类信息图形，第 17 类为用户增加的词云图。课件第 36、37 页共同归入第 15 类“编年图与编目混合图”。

17 类说明分别放入按编号排列的同名子文件夹，每个文件夹用 README.md 展示概念、A—E 分析、课件案例与后续核实内容。新增案例继续追加到对应说明中。

## 分析依据

课件标题、作品可见信息及页码构成资料依据。概念与 A—E 是根据案例进行的分析归纳，推测性的计算、分类边界及模糊的原图文字在各文件的核实部分说明。

第 09 类保留课件的层级型命名，并标明地图分级、视觉层次与父子从属的解释空间。第 15 类保留课件混合类型命名，并逐案说明能够识别的时间、分类、关系和地理编码。

## 单个案例的记录项

1. 案例编号、标题、课件页码，作者、年份与原作链接在可核实时补齐。
2. 画面中可观察的对象、图形、符号和阅读路径。
3. A 数据逻辑、B 统计与计算、C 视觉编码、D 信息架构、E 视觉叙事。
4. 图例、单位、统计范围、尺度及支持结论的证据。
5. 分类疑点、尚待核实的内容及可回写到文件夹 01 的方法。
6. 基础设计方式标签及其采用依据，例如 ISOTYPE 的符号单位、重复规则和图例。
