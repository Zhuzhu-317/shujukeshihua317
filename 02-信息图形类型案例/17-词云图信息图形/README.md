# 17 词云图信息图形（Word Cloud Infographics）

本类为用户要求增加的项目补充，提供概念与分析方法，具体案例待录入。

## 概念说明

以词语作为信息单元，通过字号表达文本中的词频或指定权重，并可用颜色、分组和注释补充类别信息。

## A 基本的数据逻辑

文本语料 → 分词 → 清洗 → 词项与权重。需要记录文本来源、范围、语言、停用词、同义词与短语处理规则。

## B 统计图形与计算方式

可使用词频、文档频次或明确说明的其他权重。记录字号映射和展示词数，跨语料比较时统一预处理及尺度。

## C 视觉编码

字号表达权重，色彩仅在有类别含义时承担分类，朝向、位置和外轮廓可组织排版。相邻词语的语义关系需要额外证据。

## D 数据／信息架构

语料说明 → 处理方法 → 权重规则与词云 → 高频词及数值 → 原句与上下文。

## E 视觉叙事架构

先通过大词识别主要话题，再查看清单与原文判断语义、态度和原因。词频高低与情感倾向分别分析。

## 案例分析

收到词云作品后，在此记录案例标题、语料范围、词频或权重规则、图例与原文证据，再按 A—E 补充逐案分析。
