# 02 文字型与列表型信息图形（Informational / List Infographics）

资料依据为《第三讲-信息图形类型学》PDF 第 23 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

以文字条目、人物资料、事实或要点为信息主体，通过模块化版面、图像和小型图表建立阅读层次，支持查阅、浏览和比较。

## A 基本的数据逻辑

条目可围绕人物或主题展开，条目内包含描述、类别与统计属性。分析时分别记录并列关系、分组规则及阅读顺序。

## B 统计图形与计算方式

披头士案例包含表格、条形和圆形小图。文字事实采用分类与对应，数量内容的具体计算需根据可读图例确认。

## C 视觉编码

中央肖像构成视觉入口，标题、分栏、插图和小图形成主次。右侧报纸案例用大幅黑白图像与文字栏形成视觉对照。

## D 数据／信息架构

主题标题 → 核心人物或主图 → 分类资料 → 统计补充 → 注释与来源。

## E 视觉叙事架构

通过主题形象吸引注意，再由资料模块支持分段阅读。大图和文字之间的相互指引决定阅读节奏。

## 案例分析

### 02-01 披头士主题资料页

中央复合肖像占据视觉中心，人物资料、潜艇插图、表格和统计小图围绕其展开，适合分析人物条目如何共享版面。

### 02-02 报纸说明版面

大幅黑白图像成为入口，周围文字分栏承载解释。路径形态可以引导视线，具体事件关系需结合正文读取。

## 核实与后续补充

确认小图的变量和单位，分别记录文字事实、统计证据与编辑判断。原作品的细小文字和数值待高清材料核实。
