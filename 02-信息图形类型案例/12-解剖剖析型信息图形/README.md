# 12 解剖型信息图形（Anatomical）

资料依据为《第三讲-信息图形类型学》PDF 第 33 页。类型名称与案例取自课件，下列概念及 A—E 为根据画面进行的分析归纳。

## 概念说明

通过剖面、透视、局部放大和部件注记展示对象的内部结构，解释组成与功能之间的对应关系。

## A 基本的数据逻辑

整体、系统、部件和功能形成组成关系，部分案例还包含位置与操作关系。

## B 统计图形与计算方式

生物结构图和机械剖面图主要以标注和空间结构解释对象。尺寸、比例和性能数值按原图实际标示记录。

## C 视觉编码

外轮廓与内部线描共同表达结构，引线、编号和局部放大建立名称对应，透视和剖切帮助显示遮挡的部位。

## D 数据／信息架构

整体形态 → 主要系统 → 部件 → 名称、功能与细节。

## E 视觉叙事架构

从熟悉的外形进入内部组成，沿功能关系理解部件如何协作。

## 案例分析

### 12-01 海马结构图

线描主体与密集注记建立器官、骨骼和局部名称的对应。

### 12-02 AT-AT 机械剖面

通过机身剖切和不同局部视图解释内部空间、机械部件及功能分区。

## 核实与后续补充

分别注明生物与虚构机械对象，比例和结构真实性需依据作品说明判断。剖切视角与实际空间关系需保持清楚。
