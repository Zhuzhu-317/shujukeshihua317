## 当前状态与更新原则

已依据《第三讲-信息图形类型学》73 页课件核对并修订现有文档。课件第 2–21 页讨论五种数据架构逻辑，第 22–38 页展示常用表现种类，第 39–61 页讨论艺术与交流，第 62–72 页讨论表达与挖掘。

五种数据逻辑帮助确定数据如何组织，常用表现种类帮助确定成品如何呈现。一个作品可同时涉及时间、分类和空间。具体案例、页码及分析方法见[案例目录](./02-信息图形类型案例/README.md)。

各文档保留 A–E 五个维度。课件直接给出的文字注明页码，从案例推导的解释标为归纳。字段设计和计算方法作为一般实施参考。图片中的小字、原始数据和完整作者信息，按可辨认程度记录为已确认或待核。

1. 案例先录入文件夹 02，保留来源、图片、分析日期与证据。
2. 可复用发现再归纳到文件夹 01，并用相对链接指回案例。
3. 文件夹 01 不保存或嵌入图片；案例图片只放在文件夹 02。
4. 结论须能追溯到课件或案例，并随案例增加持续修订。
