## 当前状态与更新原则

案例目录已依据《第三讲-信息图形类型学》第 22—38 页整理为 16 类，并补充第 17 类词云图。各类说明集中收录概念、A—E 分析、案例与核实事项。文件夹 01 的五份定义仍为待结合课程材料进一步校订的工作框架。

RAWGraphs 研究按 00—10 设置 11 个同级专题子文件夹，各目录以 README.md 展示内容。源码基准、课程分析归纳、数值复核和待运行验证分别标注，更新时在对应原文件补充。

1. 案例先录入文件夹 02，保留来源、图片、分析日期与证据。
2. 可复用发现再归纳到文件夹 01，并用相对链接指回案例。
3. 文件夹 01 不保存或嵌入图片；案例图片只放在文件夹 02。
4. 结论须能追溯到课件或案例，并随案例增加持续修订。
