## 当前状态与更新原则

当前文档已依据课程课件《第三讲-信息图形类型学》修订。课件区分两个互相关联的层面：

- 数据架构逻辑：编年型、层级型、编目型、字母表型、地理图形型。
- 常用表现种类：混合型、文字型／列表型、时间轴型，以及示意图型、比较型、地标型、过程型、图片式、单一图表型、视觉化文字、解剖型、视觉简历、手稿型、3D 型等。

1. 案例先录入文件夹 02，保留来源、图片、分析日期与证据。
2. 可复用发现再归纳到文件夹 01，并用相对链接指回案例。
3. 文件夹 01 不保存或嵌入图片；案例图片只放在文件夹 02。
4. 结论须能追溯到课件或案例，并随案例增加持续修订。
